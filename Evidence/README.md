# Evidence Overview

This folder contains supporting materials from our TechStylers Bootcamp Final Project. The project involved configuring Microsoft Entra ID, AWS IAM roles, SAML-based SSO, MFA, Conditional Access, and group-based RBAC.

# Original Project Presentation

The original Helix Group presentation documents:

- Project objectives and business requirements.
- Zero Trust identity federation architecture.
- Microsoft Entra ID groups and AWS IAM role mappings.
- MFA and Conditional Access configurations.
- SAML federation and troubleshooting challenges.
- SCIM provisioning activities.
- Security framework mapping.
- Team contributions and lessons learned.

# Additional Testing Outcomes

During the final presentation, our team successfully tested location-based Conditional Access and demonstrated access to Azure resources through AWS, as recalled by the Team Lead.

These additional results are documented retrospectively. They should not be treated as independently verified by the original presentation.
